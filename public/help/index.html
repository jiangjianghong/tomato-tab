了解如何使用本网站的各项功能

欢迎使用 Tomato Tab —— 一款功能丰富的浏览器新标签页扩展。本指南将帮助你了解和使用网站的各项功能，包括卡片导航、多引擎搜索、Notion 工作空间集成、个性化定制等。

注册与登录详解

账号安全与规则

我们的账号系统基于 Supabase 构建，提供企业级的安全认证。以下是详细的注册与使用规则：

注册限制规则

  • 用户名：必须在 2-20 个字符之间。支持中文、英文字母、数字、下划线 (_) 和短横线 (-)。不仅作为显示名称，也是您的唯一标识。
  • 邮箱验证：注册后通过正则表达式 /^[^\s@]+@[^\s@]+\.[^\s@]+$/ 严格校验格式。必须完成邮箱验证才能解锁云端同步功能。
  • 密码强度：最低要求 6 位字符。建议使用强密码以保护您的 Notion API 密钥等敏感数据。
第三方快捷登录：
Google 账号
GitHub 开发者
Notion 账号
安全机制： 系统内置了冷却机制（Cooldown），发送验证邮件或重置密码邮件后需等待 60秒 方可再次操作，防止恶意请求。
忘记密码流程：

1. 在登录页点击 "忘记密码" 链接

2. 输入注册时使用的邮箱地址

3. 系统通过 Supabase 发送重置密码邮件（触发 60 秒冷却）

4. 邮件中的链接跳转到 /reset-password 页面

5. 输入新密码完成重置（无需旧密码）

注意：仅支持邮箱注册用户，OAuth 用户（Google/GitHub/Notion）不支持密码重置

账号与安全

全方位的账号保护与多端同步机制

三方账号绑定

支持将 Google、GitHub 或 Notion 账号与当前邮箱账号绑定，实现多渠道一键登录。

  • 一键解绑：随时可在安全设置中解除绑定（需保留至少一种登录方式）。
  • 数据互通：绑定后，无论使用哪个平台登录，都能访问同一份云端数据。

智能数据同步

自动同步模式 默认开启

在设置中可切换 自动同步（默认）或 手动同步 模式。自动模式下，数据变化后会延迟一段时间再同步到云端，避免频繁请求。关闭自动同步后，所有待执行的同步定时器立即清除。

同步延迟滑块 3 - 60 秒，默认 10 秒

控制数据变化后等待多久再执行同步。这不是轮询间隔，而是每次变化后的防抖延迟。每次新变化会重置计时器，连续编辑时不会频繁触发同步。特殊规则：删除操作强制 3 秒延迟（无论滑块设置），确保快速同步关键操作。关闭设置面板或保存卡片时会立即强制同步，不受延迟限制。

数据指纹检测

系统通过 JSON 序列化生成数据指纹（包含每个卡片的 id、名称、URL、访问次数，以及 16 项关键设置如不透明度、壁纸分辨率、主题、排序等）。每次效果运行时对比当前指纹与上次同步时的指纹，完全相同则跳过同步，从根本上避免无效请求。

自动同步触发条件（全部满足才执行）

  • 1. 数据初始化已完成
  • 2. 自动同步开关已开启
  • 3. 数据指纹与上次同步时不同
  • 4. 浏览器处于在线状态
  • 5. 用户已登录且邮箱已验证
  • 6. 至少有一条有效卡片数据（或强制同步模式）
  • 7. 当前无打开的弹窗/对话框（否则延迟 5 秒后重试）

冲突解决策略：时间戳优先 (Last Write Wins)

当本地与云端数据冲突时，系统对比每条数据的 updatedAt（毫秒级时间戳），保留更新的一方。若时间戳相同，则对比 visitCount（访问次数），保留访问次数更高的版本。无论采用哪方数据，visitCount 始终取两者中的较大值，确保不会丢失访问统计。

手动同步模式

关闭自动同步后，设置中会出现两个手动按钮："上传到云端"（将本地数据覆盖到云端）和"从云端下载"（将云端数据覆盖到本地，包括同步设置本身）。仅在已登录且邮箱已验证时可用。

修改密码流程

  • 1. 进入设置 → 账号安全 → 修改密码
  • 2. 输入新密码（至少 6 位）+ 确认新密码
  • 3. 无需输入旧密码（基于 Supabase 会话认证）
  • 4. 点击"修改密码"按钮提交
  • 5. OAuth 用户（仅第三方登录）按钮显示为"设置密码"，可额外设置邮箱密码登录方式

忘记密码流程

  • 1. 在登录页点击"忘记密码"
  • 2. 输入注册邮箱地址
  • 3. 系统发送重置密码邮件（60 秒冷却防刷）
  • 4. 邮件中的链接跳转到 /reset-password 页面
  • 5. 输入新密码完成重置

注销账号

  • 1. 进入设置 → 账号安全 → 最底部"注销账号"按钮
  • 2. 第一次确认：弹窗警告"此操作不可撤销"
  • 3. 第二次确认：需手动输入 DELETE 四个大写字母
  • 4. 调用 Supabase Edge Function 删除用户数据
  • 5. 删除完成后自动登出

三方账号绑定规则

  • • 支持绑定 Google、GitHub、Notion 三种 OAuth 账号
  • • 绑定时跳转到对应平台授权页，授权后自动关联
  • • 解绑需二次确认（"确定要解绑 X 账号吗？"）
  • • 若 OAuth 账号已被其他用户绑定，提示"该账号已绑定到其他用户"
  • • 至少保留一种登录方式，不允许解绑全部

卡片管理与配置

完全掌控您的专属导航网格

添加与编辑卡片

添加新卡片

进入 设置 (Settings) > 卡片管理，点击"添加新卡片"打开编辑弹窗。

编辑弹窗包含以下字段：
  • 网址 (URL)* — 必填，需为有效 URL 格式
  • 网站名* — 必填，即卡片上显示的名称。点击"自动获取"时会从域名自动推断
  • 图标 — 可输入图标 URL 或直接上传本地图片（支持任意图片格式）。上传后自动转为 DataURL 预览
  • 标签 — 最多 2 个，每个最多 10 个字符，不允许重复。输入后按 Enter 添加。标签用于搜索匹配（权重 ×0.8）
  • 备注 — 多行文本，支持记录额外信息。备注也参与搜索匹配（权重 ×0.4）

智能获取： 输入网址后点击"自动获取"，系统将依次尝试 8 个来源（每个 3 秒超时）自动抓取标题和图标。同时自动将网站名设为域名主体（去除 www 和顶级域名）。

编辑与删除

PC端：悬停在卡片上，点击右上角的齿轮 图标。
移动端：长按卡片即可唤出编辑菜单。

编辑弹窗交互细节：
  • • 弹窗带有 3D 倾斜效果（鼠标移动时最大倾斜 8°）
  • • 关闭按钮悬停时旋转 90°
  • • 按 Esc 键可快速关闭
  • • 保存时若图标有变化，会自动上传到云端存储
删除流程：

点击弹窗最下方的红色 "删除卡片" 按钮，弹出确认框 "确定要删除这个卡片吗？"，确认后删除并关闭弹窗。

布局与排序

1
自由拖拽 (Drag & Drop)

按住卡片即可随意拖动调整位置。松手后系统自动保存布局顺序。默认关闭自动排序时使用此模式。

2
智能自动排序

在设置中开启 "自动排序"（默认关闭）后，卡片将根据访问频率动态排列，访问越多的卡片越靠前。开启后手动拖拽的顺序会被覆盖。

Favicon 图标系统

系统采用多级策略获取图标，确保最佳显示效果：

添加卡片时自动获取（按优先级逐个尝试，每个来源 3 秒超时）

  1. favicon.im (通过代理): 优先使用 allorigins.win 代理访问 favicon.im，绕过跨域限制。
  2. favicon.im (直连): 代理失败时尝试直连 favicon.im。
  3. Google S2 64px: 使用 Google S2 Favicon 服务获取 64 像素高清图标。
  4. Google S2 32px: 降级到 32 像素版本。
  5. DuckDuckGo Icons: 使用 DuckDuckGo 图标服务。
  6. 网站 /favicon.ico: 直接访问目标网站根目录的 favicon.ico 文件。
  7. 网站 /favicon.png: 尝试访问 favicon.png 格式。
  8. 默认图标： 以上全部失败时使用系统内置默认图标。

日常显示时（卡片在主页上的图标加载路径）

  1. 云端 CDN： 优先从 Supabase Storage 加载已缓存的图标，速度最快。
  2. Edge Function： 通过服务器端代理获取，绕过浏览器跨域限制。
  3. favicon.im： 客户端直连获取。
  4. 原始 URL： 直接从目标网站加载。
  5. 默认图标： 全部失败时的兜底方案。

图标缓存机制：系统会自动清除超过 3 天的旧图标缓存（每 6 小时检查一次），确保获取到网站最新的品牌标识。如果图标仍显示异常，可在设置的卡片管理区使用 "一键修复图标" 按钮，它会清除当前所有图标缓存并刷新页面，强制重新获取所有图标。

个性化定制

打造独一无二的专属主页

视觉微调

搜索框不透明度 5% - 50%

滑块控制搜索框背景的透明程度。默认 10%，数值越高背景越不透明。

卡片不透明度 5% - 50%

独立于搜索框，单独控制卡片背景的透明程度。默认 10%。

搜索框圆角 0 - 50px

调节搜索框的圆角大小。默认全圆角。拖到最右 (50px) 为完全胶囊形，拖到最左 (0px) 为硬朗直角。

搜索框颜色 8 色可选

提供黑、白、红、黄、蓝、绿、紫、粉 8 种预设颜色，点击即切换。默认白色。

卡片颜色 8 色可选

与搜索框颜色独立设定，同样 8 种预设。默认白色。

动画质感 灵动 / 简约

灵动 (Dynamic)：弹簧动画，搜索框展开时有果冻般回弹效果。简约 (Simple)：匀速平滑过渡。默认简约。

视差背景 开 / 关

开启后，鼠标移动时壁纸会随之轻微平移，营造纵深感。默认开启。搜索框聚焦时自动暂停视差效果。

链接打开方式 新标签 / 当前页

控制点击卡片、搜索结果、AI 助手时的跳转行为。默认新标签页打开。

壁纸遮罩 3 种模式

关闭：不添加遮罩。始终：始终在壁纸上覆盖暗角。智能：仅在搜索框聚焦时显示。默认智能。

壁纸系统

每日必应 (Bing Daily) 默认壁纸源

  • 4K 超高清：适合大屏显示器（分辨率 UHD）
  • 1080P 高清：平衡清晰度与加载速度（1920×1080）默认
  • 720P 标清：加载更快，适合弱网环境（1366×768）
  • 竖屏适配：移动端专属优化

自动更新：每日自动获取新壁纸。壁纸缓存有效期 48 小时，页面可见时自动检查是否需要更新。下载失败时自动重试（30s → 60s → 120s → 240s，最多 8 次），有旧缓存时先显示旧壁纸再后台下载新的。过期超过 3 天的缓存自动清理（每 6 小时检查）。

自定义上传

支持全屏拖拽上传或点击选择
格式 JPG/PNG/WebP，最大 10MB

上传后自动保存原图到浏览器本地数据库（IndexedDB），有效期 1 年。同时自动生成 300px 宽缩略图用于壁纸库列表预览。在设置中可管理已上传的壁纸：预览、删除、下载到本地、设为当前壁纸。

壁纸收藏与管理

搜索框聚焦时，右上角会出现 心形按钮，点击即可收藏当前 Bing 壁纸到本地壁纸库。在设置中可以管理已收藏的壁纸列表，支持预览、删除和一键设为当前壁纸。

主题与氛围

夜间模式 默认跟随系统

  • 跟随系统：自动适配操作系统的深浅色模式
  • 定时切换：自定义时间段自动切换（默认 22:00 开启 → 06:00 关闭）
  • 始终开启：强制深色模式
  • 始终关闭：强制浅色模式

深色模式下壁纸会自动适配深色滤镜。

氛围粒子效果 默认自动

  • 自动模式：根据季节智能切换（冬季→雪花、秋季→落叶，其他季节关闭）
  • 雪花飘落：冬季专属，双层 Canvas 实现远近景深度
  • 落叶纷飞：秋季氛围
  • 樱花飘落：春日浪漫
  • 萤火虫：夏夜微光
  • 关闭：不显示任何粒子效果

粒子数量：可调节 1-100（默认 30），数值越高粒子越密集。

风力效果：开启后粒子会受风力影响产生横向飘移（默认开启）。

慢放效果：在主页空白区域按住鼠标左键，粒子速度降至 10%（慢动作），松手恢复。切换效果时旧粒子会加速飘走退场，新粒子 1.2 秒内逐步补满。

时间与效率

时间显示 默认开启

  • • 格式：24 小时制，显示 HH:MM，开启秒数后显示 HH:MM:SS
  • • 秒数开关：可关闭，关闭后仅显示时:分，冒号每 500ms 闪烁
  • • 日期：中文格式，可独立控制年/月/日的显示开关
  • • 星期：显示为"星期X"格式，可单独开关
  • • 位置：搜索框上方居中
  • • 点击交互：点击时间文字可直接打开待办事项 (Todo) 弹窗

下班 / 午休倒计时 默认关闭

开启后，鼠标悬停在时间区域时切换显示倒计时，移开恢复显示日期。

  • • 午休时间：默认 12:00，可自定义
  • • 下班时间：默认 18:00，可自定义
  • • 午休前：显示"距离午休: X时X分X秒"
  • • 午休后-下班前：显示"距离下班: X时X分X秒"
  • • 下班后：显示"已下班，好好休息吧"

搜索与命令系统详解

搜索框是本应用的控制中枢。它不仅支持多引擎搜索，还集成了完整的命令行系统 (Command Line)，让您无需鼠标即可掌控全局。

搜索框交互行为

未聚焦状态

  • • 默认宽度 340px（移动端 200px），居中显示
  • • placeholder 文字 "搜点啥捏..."
  • • 左侧显示当前搜索引擎图标 + 名称
  • • 悬停时宽度扩展到 520px（移动端 300px），弹簧动画
  • • 按 Space 聚焦

聚焦状态

  • • 页面出现半透明黑色遮罩 + 背景模糊效果
  • • 搜索框宽度固定 520px
  • • 设置按钮和工作空间按钮淡出缩小
  • • 壁纸视差效果暂停
  • • 右上角出现壁纸收藏心形按钮（仅 Bing 壁纸时）
  • • 底部显示每日诗词
  • • 输入内容后 300ms 防抖，显示搜索建议
  • • 建议列表最多 5 条，分三个区块：网站(紫色)、工作空间(蓝色)、搜索(绿色)
  • • 按 Esc 或点击遮罩失焦

常见问题 (FAQ)

Q: 如何切换其他 Notion 账号？

点击设置页右上角的 "断开连接" 按钮，然后重新点击连接并选择不同的 Notion 账号登录即可。断开后本地缓存的数据库配置会被清除。

Q: 如何更换绑定的数据库？

在已连接状态下，您可以直接在下方的数据库列表中点击切换。如果没有看到您想要的数据库，请点击列表上方的 "重新授权" 按钮，并确保在 Notion 授权页勾选了该页面。一个 Notion 账号下可以有多个数据库，系统会列出所有可访问的数据库供选择。

Q: 更换电脑或浏览器需要重新配置吗？

需要。为了安全，数据库配置（Notion API 密钥和数据库 ID）仅保存在当前浏览器的本地存储中。不过您的 OAuth 授权信息是云端保存的，在新设备上点击连接通常会自动识别，只需再次确认选择数据库即可。

Q: 工作空间数据会自动同步吗？

工作空间数据直接从 Notion API 实时读取，每次打开工作空间面板时都会拉取最新数据。这与卡片数据的 Supabase 云同步是两套独立机制——工作空间走 Notion 通道，卡片和设置走 Supabase 通道。

Q: 为什么搜索框搜不到工作空间的内容？

搜索框会同时搜索本地卡片和 Notion 工作空间数据，但需要工作空间数据已加载（即至少打开过一次工作空间面板）。搜索结果中工作空间匹配项显示为蓝色区块，带分类标签和 URL。

Q: 卡片视图的 3D 翻转怎么用？

在卡片视图下，点击卡片右下角的 眼睛图标，卡片会以 Y 轴旋转 180°（0.7 秒动画）展示背面的账号和密码信息。再次点击翻转回来。如果该条目没有密码，背面会显示锁图标和"无需登录信息"提示。

行为细节与小贴士

  • Space 键的双重身份：在主页未聚焦搜索框时，按 Space 聚焦搜索框。在搜索框已聚焦且内容为空时，按 Space 退出聚焦（失焦）。这意味着 Space 键在搜索框场景下既是"打开"也是"关闭"。
  • Tab 键切换引擎时会触发粒子烟花特效，提供视觉反馈。切换顺序为所有已启用引擎的循环顺序（在设置中可调整启停状态）。
  • Esc 键的渐进式行为（工作空间内）：按第一次 → 清除搜索框内容；按第二次 → 取消当前选中的卡片/列表项；按第三次 → 关闭整个工作空间面板。在搜索框聚焦状态下按 Esc 则直接失焦并关闭建议列表。
  • 数字键 0-9 在工作空间中可快速切换分类，0 对应"全部"，1-9 对应第 1-9 个分类。超出实际分类数量的数字键无效果。
  • 方向键导航在工作空间中支持上下（列表视图）和上下左右（卡片视图）。焦点项有蓝色边框动画跟随，到达列表首尾时自动循环。
  • D 键 / Space 键在工作空间中用于展开/折叠当前选中项的密码信息（仅在已选中某项时生效）。C 键复制当前选中项的 URL 到剪贴板，复制成功后显示绿色提示。
  • 在设置、TODO、卡片编辑等所有模态框中按 Esc 都可以快速关闭。TODO 编辑中 Enter 保存，Shift+Enter 换行。
  • 搜索建议导航：↑↓ 键在建议列表中移动选中项（最多 5 条），到达顶部再按 ↑ 或底部再按 ↓ 时循环。按 Enter 打开选中建议，未选中时直接执行搜索。

隐私与数据架构

本地优先架构 (Local-First)

我们的核心架构基于 IndexedDB 和 LocalStorage。您的卡片配置、UI 偏好设置、壁纸缓存、自定义上传壁纸等均完全存储在您的浏览器本地数据库中。即使不登录、不联网，所有功能均可正常使用。

端到端数据流

当您连接 Notion 时，API 密钥仅保存在您的浏览器本地存储中，我们仅作为"客户端"直接与 Notion 官方 API 通信。您的数据流向为：浏览器 ↔ Notion API，中间不经过我们的服务器中转。

完全的数据掌控权

导出数据

一键导出为标准 JSON 文件（格式化缩进 2 空格）。文件名格式：我的数据导出_YYYY-MM-DD.json。导出内容包含所有非必要 LocalStorage 键（解析为 JSON 对象）。需先同意 Cookie 政策才可导出。

导入数据

选择之前导出的 .json 文件即可恢复配置。文件类型校验：必须为 .json 扩展名且 MIME 为 application/json。文件大小限制：5MB，超出则提示"文件过大"。导入前弹出确认对话框，确认后覆盖所有现有配置数据。实现跨设备迁移。

清除所有数据

清除浏览器中所有非必要 LocalStorage 数据。不会清除 IndexedDB（壁纸缓存等二进制数据仍在）。始终保留的键：cookie-consent（Cookie 同意状态）和 cookie-consent-date（同意日期），确保合规记录不丢失。清除后页面需刷新生效。

云端同步数据流

登录并验证邮箱后，可开启云端同步。数据通过 Supabase 实时存储，同步内容包括卡片列表和全部 UI 设置。详见上方"智能数据同步"章节了解触发条件和冲突解决策略。

存储层级总结：LocalStorage（设置偏好、同步状态）→ IndexedDB（壁纸缓存、二进制数据）→ Supabase 云端（登录后同步备份）→ Notion（工作空间数据，独立通道）
